併發與節流

併發越高越快，但較容易遇到 403、429 或逾時；填寫隨機延遲後會取代固定間隔。

最小值與最大值都填寫時才會啟用隨機延遲，例如 300 到 1000 ms；兩者相等時，只代表每個任務先等固定時間。若單一 host 併發大於 1，仍可能同時送出多個請求。

請求可靠性

慢站可提高逾時；重試只適合暫時性錯誤，不會修正一般 404 / 410 或 403。

Redirect

HTTP 行為與標頭
