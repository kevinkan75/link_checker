掃描模式與進階設定 300 頁 / 深度 3 / 併發 6 / 每 host 2 / 固定 1000ms

一般網站建議使用標準保守；快速掃描較快，但較容易遇到 403、429 或逾時。

爬取範圍

限制站內頁面爬取範圍；最多頁面不等於總 URL 檢查數。

併發與節流

併發越高越快，但較容易遇到 403、429 或逾時；填寫隨機延遲後會取代固定間隔。

最小值與最大值都填寫時才會啟用隨機延遲，例如 300 到 1000 ms；兩者相等時，只代表每個任務先等固定時間。若單一 host 併發大於 1，仍可能同時送出多個請求。

請求可靠性

慢站可提高逾時；重試只適合暫時性錯誤，不會修正一般 404 / 410 或 403。

轉址

控制最多追蹤幾次轉址；轉址過長會標記為需要檢視。

HTTP 行為與標頭

GET 較接近瀏覽器但較慢；外部 Referer 可降低部分誤判，但會把來源頁送給外部站。
